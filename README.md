# Shipping Cost Calculator
 
## Description
 
This program calculates shipping costs using three different shipping methods:
 
- Ground Shipping
- Ground Shipping Premium
- Drone Shipping
 
The package weight is stored in the `weight` variable, and the program calculates the cost for each shipping option.
 
## Input
 
```python
weight = 41.5
```
 
## Ground Shipping
 
Ground shipping includes a flat fee of **$20** plus a rate based on package weight.
